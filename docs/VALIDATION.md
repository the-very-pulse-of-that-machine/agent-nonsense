- Responses、Chat Completions、Messages 三种有限流输出和 Markdown 渲染。

- 服务停止后重新启动。
- 后台任务创建、活动查询和停止。
- 端口被占用时不会接管或关闭外部监听器。
- 无效预设不会覆盖原文件，也不会启动服务。
- 有效预设修改、目录更新、设置持久化。
- 切换剧本同步问题并清理旧输出；连续流中切换对话或协议并立即重发。
- 快速连续切换只显示最后选中的对话；输出中重新发送修改后的请求。
